# Mini Projet Web HTML/CSS

Structure de base du projet.

- `Sujet/` : sujet et ressources du projet.
- `Cahier des charges/` : besoins, objectifs et contraintes.
- `code/` : fichiers HTML, CSS et ressources du site.
- `.github/` : configuration GitHub (règles de contribution, modèle de Pull Request, vérification automatique).

Avant de contribuer, lire [les règles de contribution](.github/CONTRIBUTING.md).
